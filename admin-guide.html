团长操作手册

本手册适合已经完成首次部署的团长，介绍每次团购的完整操作流程。

一、登录后台

浏览器打开 你的网址#admin，输入管理密码进入后台。

后台左侧有五个功能标签：商品管理、订单汇总、收款清单、下单二维码、轮次设置。

二、创建团购轮次

1

左侧菜单 → 轮次设置 → 点击「创建新轮次」

  • 填写轮次名称（如「5月第一周团购」）
  • 设置下单截止时间（选填，到期自动关闭下单）
  • 点击「创建」
新轮次创建后自动启用，之前的历史轮次会自动归档。每次团购创建一个新轮次，订单和收款按轮次分开管理。

三、添加商品

2

左侧菜单 → 商品管理 → 点击「添加商品」

  • 商品名称（必填）— 如「烟台红富士苹果」
  • 商品图片（选填）— 支持 JPG/PNG/GIF/WebP，最大 5MB
  • 规格与价格（至少一个）— 如「500g / 15 元」「1kg / 28 元」
  • 商品标签（选填）— 如「蛋糕」「冷藏」，用空格分隔
  • 库存数量（选填）— 不填则不限库存，卖完自动显示「已售罄」
  • 点击「添加商品」
商品默认上架，可在列表中点击「下架」暂时隐藏。

四、生成下单二维码

3

左侧菜单 → 下单二维码

二维码自动生成，指向顾客下单页面。长按保存后发到业主微信群，邻居扫码即可下单。也可点击「复制下单链接」直接分享。

五、查看订单

4

左侧菜单 → 订单汇总

  • 顶部下拉可选择不同轮次的订单
  • 按人分组显示订单明细和金额
  • 底部「本轮商品汇总」列出所有商品的总量
  • 可「复制采购清单」粘贴到美团优选等平台统一采购
  • 点击「导出 Excel」下载订单表格用于备货对账

六、收款

5

左侧菜单 → 收款清单

  • 设置本轮费用（运费、包装费等），系统自动按人数均摊
  • 底部「收款清单」列出每人应付金额，可逐条复制
  • 截止后按清单发起群收款

七、常见操作

编辑商品

商品管理 → 点击商品右侧「编辑」→ 修改后点「保存修改」。已下架商品编辑后不会自动上架。

上下架商品

商品管理 → 点击「下架」隐藏商品，顾客端不可见。再点击「上架」恢复。

删除商品

商品管理 → 点击「删除」→ 确认。该商品会从本轮所有订单中移除并重新计算金额。

停用 / 归档轮次

轮次设置 → 点击历史轮次的「启用」可切换活动轮次。点击「删除」可删除非活动轮次及其所有订单。

修改站点标题

轮次设置 → 站点标题输入框 → 输入新标题 → 保存。顾客端顶部会显示。

修改管理密码

轮次设置 → 管理密码区域 → 输入新密码 → 保存。

忘记密码

在 Supabase → SQL Editor 执行：

UPDATE settings SET value = '' WHERE key = 'admin_password';

然后重新打开 #admin 设置新密码。

八、小贴士

  • 售罄商品会自动沉到列表底部，显示「已售罄」标记，顾客无法加购
  • 库存会每 10 秒自动刷新，多设备同时下单不会超卖
  • 顾客下单后在页面顶部「查/改订单」可自行查询和取消
  • 后台商品编辑时不会改变上下架状态
  • 历史轮次可在订单汇总下拉中查看，不会丢失
