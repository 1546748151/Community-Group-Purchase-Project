团长操作手册

本手册适合已经完成首次部署的团长，介绍每次团购的完整操作流程和常用功能。

一、登录后台

浏览器打开 你的网址#admin，输入管理密码进入后台。

后台左侧有五个功能标签：商品管理、订单汇总、收款清单、下单二维码、轮次设置。

二、创建与管理轮次

1

左侧菜单 → 轮次设置 → 点击「创建新轮次」

  • 填写轮次名称（如「5 月第一周团购」）
  • 可选填写本期团长名（顾客端会显示）
  • 设置下单截止时间（选填，到期后顾客端自动显示「已截止」并关闭下单）
  • 点击「创建」，轮次进入「策划中」状态
轮次有四种状态：
· 策划中 — 刚创建，不可下单，顾客端看不到
· 进行中 — 已开团，顾客可浏览商品和下单
· 已截止 — 到达截止时间自动变更，不可再下单
· 已停止 — 团长手动停止，等同已截止
允许多个轮次同时「进行中」，不同轮次的商品和订单完全隔离。

添加商品完成后，点击该轮次的「开团」按钮使其变为「进行中」，顾客端才可见。

进行中可点「停止」提前结束；已停可点「启用」重新开团。只有已停止的轮次才能「删除」（会同时删除该轮次所有订单和商品，不可恢复）。

批量操作

轮次设置页支持：一键停止所有进行中轮次、一键启用所有已停止轮次、多选删除（勾选后批量删）、一键删除所有非进行中轮次。

三、添加商品

2

左侧菜单 → 商品管理 → 选择轮次 → 点击「添加商品到「轮次名」」

  • 商品名称（必填）— 如「烟台红富士苹果」
  • 商品图片（选填）— 支持 JPG/PNG/GIF/WebP，最大 5MB，点击可放大预览
  • 规格与价格（至少一个）— 如「500g / 15 元」「1kg / 28 元」，可添加多个规格
  • 整装拆分计算器 — 适用于山姆、开市客等大包装商品。输入整装数量、总价、每份大小，一键生成拆分规格
  • 商品标签（选填）— 如「蛋糕 冷藏」，用空格分隔，顾客端可按标签筛选
  • 标签排序 — 标签旁的「排序」按钮可自定义标签显示顺序，顾客端同步
  • 库存数量（选填）— 不填则不限，卖完自动显示「已售罄」并停止加购
  • 点击「添加商品」，商品默认上架
拆分商品命名格式为「5/30个/份」，表示从 30 个一盒中拆成每份 5 个出售。顾客端按份显示和购买，库存按份扣减。整装规格（如 30/30）优先显示。

四、称重商品

适用于山姆等平台的称重商品（如排骨、大排等，只有单价没有确定总价）。

添加商品时勾选「称重商品」，表单会切换为称重模式：

  • 单位价格（必填）— 选择 ¥/kg 或 ¥/份，作为计算单价
  • 预估克重（选填）— 如「约 800g/份」，顾客端参考用
  • 规格自动生成 — 保存后自动生成「1份」规格。可手动补充「1/2份」「1/3份」等
  • 顾客下单后订单状态为「待称重确认」，不计入收款总额
  • 到货后，团长进入订单汇总→「称重分配」，录入每人的实际重量
  • 系统自动计算：单价 × 实际重量 × 份额 = 最终价格
  • 确认后订单转正式，计入收款清单和导出 Excel

五、开团与生成二维码

3

商品添加完毕后，到 「轮次设置」 点击该轮次的「开团」按钮。

然后进入 「下单二维码」 标签页，保存图片发到业主微信群即可。

六、查看与处理订单

4

左侧菜单 → 订单汇总

  • 顶部下拉选择轮次，按人分组显示订单明细（同商品自动合并、显示最后下单时间）
  • 顶部统计卡片显示订单数和总金额
  • 底部「采购清单」按商品汇总采购量，显示拼单状态，一键复制
  • 点击「导出 Excel」下载含「订单明细」和「商品汇总」两个 sheet 的表格

砍单功能

点击订单下方的「砍单」按钮：

  • 弹窗列出该顾客的所有商品，可输入取消数量（支持部分取消，如顾客 B 的 4/3 份中只取消 2/3 份）
  • 弹出确认弹窗，可填写砍单原因（选填，如「缺货」「规格不符」）
  • 确认后取消部分被标记，保留部分自动生成新订单
  • 顾客查单时会看到红色「已砍单」标签和砍单原因

七、收款

5

左侧菜单 → 收款清单

  • 设置本轮费用（运费、包装费、其他费用），系统自动按人数均摊到分
  • 底部收款清单列出每人应付金额：商品金额 + 均摊费用
  • 称重确认后的订单才会计入收款
  • 点击「一键复制收款清单」后到微信发起群收款

八、常见操作

编辑商品

商品管理 → 点击商品右侧「编辑」→ 修改后点「保存修改」。已有订单时规格名称自动锁定不可修改。

上下架/删除商品

商品管理 → 点击「下架」隐藏商品。点击「删除」将商品从所有订单中标记为已删除。

导入导出商品

商品管理 →「导出商品」下载 Excel，「导入商品」批量恢复。适合轮次间复用商品配置。

整装拆分计算器

在添加/编辑商品弹窗中展开计算器，填入整装数量、单位、总价、每份大小，一键添加拆分规格。

修改站点标题和密码

轮次设置 → 顾客端标题/管理密码 → 输入新值 → 保存。

查看顾客反馈

轮次设置 →「顾客反馈」→「查看反馈」，可以看到顾客提交的文字和截图，点击「标记已读」归档。

忘记密码

在 Supabase → SQL Editor 执行：

UPDATE settings SET value = '' WHERE key = 'admin_password';
然后重新打开 #admin 设置新密码。

九、小贴士

  • 售罄商品自动沉底，显示「已售罄」标记
  • 库存每 10 秒自动刷新，多人同时下单不会超卖（数据库行锁保护）
  • 顾客可自行查单和部分取消，取消的商品回到购物车
  • 顾客查单会看到订单所属轮次、状态、最后下单时间和称重计算公式
  • 轮次切换时顾客购物车自动清空，搜索和标签筛选重置
  • 允许多个轮次同时进行中，不同品类分开团购
  • 商品可导出 Excel 再导入到新轮次
  • 弹窗只能通过取消按钮或 ESC 关闭，不会误触空白处
